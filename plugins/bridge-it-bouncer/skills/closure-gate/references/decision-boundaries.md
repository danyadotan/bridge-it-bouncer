# Decision boundaries

Use this matrix to decide whether work can continue or requires human judgment.

| Situation | Gate disposition |
| --- | --- |
| Duplicate wording or formatting | Consolidate or pass silently |
| Verified, reversible work within delegated authority | Pass silently |
| Missing source, contradiction, or unsupported urgency | Return for correction |
| New or expanded access to personal or confidential data | Block and return for privacy and authorization review |
| Material change to price, deadline, scope, ownership, or responsibility | Escalate after verification |
| New external commitment or representation | Escalate |
| Financial, legal, medical, safety, or employment consequence | Escalate with the minimum supporting context |
| Irreversible or destructive action | Require explicit human confirmation immediately before action |
| Unclear authority boundary | Return for clarification; do not infer permission |

## Materiality test

Treat a change as material when it alters at least one of:

- what will happen;
- who is responsible or exposed;
- cost, timing, scope, or quality;
- access to data or systems;
- reversibility or downstream risk;
- an external promise, obligation, or public statement.

## Human-attention test

Before escalating, confirm:

1. The facts are verified or uncertainty itself is the decision.
2. Agents cannot resolve the issue using existing authority and evidence.
3. The person has the authority and context to decide.
4. The decision cannot be safely deferred, automated, or returned.
5. The presented information is the minimum needed for sound judgment.
